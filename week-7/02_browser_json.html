Try these before moving on

  1. Set forecast_days to 1, then 16. How many numbers are in hourly.temperature_2m each time? Watch the Chart tab redraw.
  2. Compare Lisbon and Chicago on the same day. Which has the wider daily swing?
  3. Switch the timezone and compare the first entry of hourly.time. The temperatures do not change — only the labels do.
